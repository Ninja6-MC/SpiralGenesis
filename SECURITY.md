# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within SpiralGenesis, please do not open a public issue.

Instead, please report the vulnerability privately by:
1. Creating a [Private Security Advisory](https://github.com/Ninja6-MC/SpiralGenesis/security/advisories/new) on GitHub.
2. Providing detailed steps to reproduce the exploit or security issue.

We will acknowledge receipt within 48 hours and work with you to release a patched hotfix version.
